# Rehearsal media

The cover depicts a fictional tailoring worktable. OpenAI ImageGen generated the scene from a brief for an ordinary keypad phone, indigo fabric, measuring tape and a sewing machine in a Tamil home tailoring workspace. The repository contains a compressed WebP and a cover layout.

The customer lines and feedback clips were written for the tailoring exercise and synthesized with Piper. The coach has separate clips for a missing fee, a missing pickup, a complete offer, a retry and an unrecognised answer. The walkthrough uses the same audio and captures of the running rehearsal. Its on-screen text describes each step.

- Tamil uses tinisoft’s Rasa Female medium Piper model, trained on AI4Bharat Rasa. The model card credits Praveen Srinivasa Varadhan, Ashwin Sankar, Giri Raju and Mitesh M. Khapra, *Rasa*, Interspeech 2024. [Tamil model and CC BY 4.0 attribution](https://huggingface.co/tinisoft/piper-ta_IN-rasa_female-medium) · [Rasa paper](https://arxiv.org/abs/2407.14056)
- English uses Rhasspy’s US English Lessac medium Piper model. [English model card and dataset credits](https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_US/lessac/medium/MODEL_CARD)

## Live AI call sample

The sample plays the real opening and response from the configured Sarvam browser agent on November 19, 2026. The caller is a synthetic English voice reading a fictional tailoring request. We combined the two captured agent segments and the caller’s input in their original conversational order, then shortened pauses. The sample contains no learner recording or telephone number.
