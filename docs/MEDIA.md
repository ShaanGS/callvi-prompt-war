# Demo media

The cover and walkthrough use the running Callvi interface, including its original voice orb, wordmark and typography. The lesson questions and feedback audio are prerecorded from the team-authored English and Tamil curriculum using Piper. The Tamil voice is tinisoft’s Rasa Female medium model, trained on AI4Bharat Rasa. The English voice is Rhasspy’s Lessac medium model. [Tamil model and attribution](https://huggingface.co/tinisoft/piper-ta_IN-rasa_female-medium) · [Rasa paper](https://arxiv.org/abs/2407.14056) · [English model card](https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_US/lessac/medium/MODEL_CARD)

The call sample captures a live Sarvam browser agent responding to a synthetic learner. The captured agent and fictional caller audio appear in conversational order with pauses shortened. The physical handset channel still requires a verified inbound deployment.
